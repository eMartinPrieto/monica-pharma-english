# English for Monica - Pharma English Quest

Web mobile-first para practicar ingles de farmacia con lecciones, tests y roleplays.

## Como subirlo a GitHub Pages

1. Sube todos los archivos a un repositorio publico llamado `monica-pharma-english`.
2. Ve a Settings > Pages.
3. En Source elige `GitHub Actions`.
4. Espera a que termine el workflow en la pestana Actions.
5. La web quedara en `https://TU_USUARIO.github.io/monica-pharma-english/`.
